# Steel_CocoonV2

Прототип шутера с механикой линейки-прицела, системой попаданий/промахов и выходом по ESC.

## Особенности
- Линейка-прицел для наведения
- Звуковое сопровождение попаданий и промахов
- Выход из игры по клавише ESC

## Как запустить
1. Открыть проект в Unity.
2. Открыть сцену в папке `Assets/Scenes`.
3. Нажать Play.
